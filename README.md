# Join Scouting Night — Fall 2026

A one-page site for the Fall 2026 Cub Scout Join Scouting Night recruiting flyer.
Each elementary school on the flyer is a clickable region that opens that school's
digital flyer (Google Slides). Hovering a school highlights it and shows "Click Here".

- `index.html` — the page (flyer image + clickable overlays, no dependencies)
- `jsn_flyer.png` — the recruiting flyer graphic (1920×1080)

School → flyer links are defined in the `SCHOOLS` table inside `index.html`.
Published via GitHub Pages.
